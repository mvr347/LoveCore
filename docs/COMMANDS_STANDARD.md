# Стандарт команд Love*

Единые правила для команд всех плагинов экосистемы. Дата: 2026-10-29.

## 1. Нет прав — тишина

Игроку, которому команда недоступна, она не нужна: никаких сообщений «нет прав» в чате.

- Право объявляется в `plugin.yml` (`permission:`) вместе с `permission-message: ""` — Bukkit не отправляет
  ничего, а команда пропадает из tab-complete.
- Проверка права внутри кода (подкоманды, команды без `permission:` в yml) — тихий `return true`.
- Исключение: отказ, объяснимый состоянием, а не правом (нет клана, мало денег, кулдаун). Это ответ на
  действие, а не «нет прав», и он остаётся.

## 2. Консоль

- Подкоманды, которым нужен только аргумент (reload, give/set/info с ником, help, list), работают из консоли.
- `Player` приводится только внутри подкоманды, которая использует позицию, взгляд, GUI или предмет в руке.
- Консоль всегда получает ответ: `Команда доступна только игрокам.` Молчаливый `return` недопустим.
- Автор в журнале/аудите для консоли — имя отправителя (`Console`) и нулевой UUID.
- Глобальный `if (!(sender instanceof Player)) return` до `switch` по подкомандам запрещён.

## 3. Справка

MiniMessage, команды — простым текстом (угловые скобки аргументов не должны разбираться как теги):

```
========== {Плагин} Помощь ==========        <dark_gray> + <aqua> заголовок
/cmd <аргументы> - описание                  <aqua> команда, <gray> описание
=========================================
```

- Неизвестная подкоманда и пустой вызов показывают справку, отдельной ошибки нет.
- В справке — только команды, доступные отправителю.

## 4. Сообщения

- Формат — MiniMessage. Старые `§`/`&` в командах переводятся; где у плагина есть терпимый парсер
  (`Utils.color`, `TextUtil.parse`) — он остаётся ради существующих конфигов.
- Префикс плагина — только на ошибках и системных уведомлениях, не на справке, успехе и info.
- Usage — одной строкой `<red>/cmd <аргументы></red>`.

## 5. Имена и права

- Игровая команда `<плагин>`, админская `<плагин>admin`, право `<плагин>.admin`.
- Русские варианты — `aliases:`, а не отдельные записи `commands:` в `plugin.yml`.
- Алиас не должен совпадать с именем/алиасом команды другого плагина экосистемы или с ванильной командой.
- У каждой команды в `plugin.yml`: `description`, `usage`, `permission` (если она ограничена), `permission-message: ""`.

## 6. Проверка

Сверка конфликтов имён и алиасов по всем `plugin.yml`: `scripts/check-command-collisions.py`.
